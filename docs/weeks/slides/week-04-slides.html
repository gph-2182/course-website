Cycle 1: The Grammar of Graphics & Scatterplots

Why ggplot2?

Created by Hadley Wickham based on Leland Wilkinson's The Grammar of Graphics.

Base R Graphics (plot())

  • Fast for quick sketches.
  • Hard to customize multi-layer legends, colors, and facets.
  • Uses pen-on-paper model (cannot easily modify earlier elements).

ggplot2 (library(ggplot2))

  • Layered system: Add data, aesthetics, geometries, facets, and themes step-by-step using +.
  • Automatic, consistent legends and scales.
  • Standard across global health, epidemiology, and statistical science.

The 3 Core Components of Every Plot

ggplot(data = <DATA>, mapping = aes(<MAPPINGS>)) +
  <GEOM_FUNCTION>()
  1. Data: A data.frame or tibble.
  2. Aesthetic Mapping (aes()): How variables connect to visual properties (\(x\)-axis, \(y\)-axis, color, size, shape, alpha).
  3. Geometry (geom_*()): The visual shape representing data points (points, lines, bars, boxes).

Building a Scatterplot: Step-by-Step

library(ggplot2)

# Step 1: Canvas (blank)
p <- ggplot(data = airquality, aes(x = Temp, y = Ozone))

# Step 2: Add Points
p + geom_point()

# Step 3: Map a 3rd Variable to Color (Month)
p + geom_point(aes(color = factor(Month)), size = 2.5, alpha = 0.8)

Mapping vs. Setting Aesthetics

  • Inside aes(): Maps a variable from your dataset (e.g. aes(color = Month)).
  • Outside aes(): Sets a fixed constant for all points (e.g. color = "navy", size = 3).

Common Beginner Mistake

# ❌ INCORRECT: puts "blue" in legend!
geom_point(aes(color = "blue"))

# ✅ CORRECT: sets color of all points
geom_point(color = "blue")

Cycle 2: Visualizing Distributions

1. Single Continuous Variable: Histograms & Density

Histogram (geom_histogram)

ggplot(airquality, aes(x = Temp)) +
  geom_histogram(
    binwidth = 5,
    fill = "#3498db",
    color = "white"
  )
  • Always experiment with binwidth!

Density Curve (geom_density)

ggplot(airquality, aes(x = Temp, fill = factor(Month))) +
  geom_density(alpha = 0.4)
  • Shows smooth probability density estimates across subgroups.

2. Comparing Groups: Boxplots & Violins

# Boxplot with overlaid jittered points
ggplot(airquality, aes(x = factor(Month), y = Ozone, fill = factor(Month))) +
  geom_boxplot(outlier.shape = NA, alpha = 0.7) +
  geom_jitter(width = 0.2, alpha = 0.5, color = "black")

Why Boxplots?

  • Displays the 5-number summary (Min, Q1, Median, Q3, Max) + outliers.
  • Robust against extreme skewness.

Adding Jittered Points (geom_jitter)

  • Prevents overplotting and reveals exact sample size and density clusters.

3. Discrete Counts: geom_bar vs geom_col

geom_bar() (Counts Rows)

When R calculates frequency for you:

# Data has raw individual rows
ggplot(airquality, aes(x = factor(Month))) +
  geom_bar(fill = "steelblue")

geom_col() (Pre-Summarized)

When data already has a numeric height column:

# Data has pre-computed totals
summary_df <- data.frame(
  region = c("North", "South", "West"),
  admissions = c(120, 340, 210)
)
ggplot(summary_df, aes(x = region, y = admissions)) +
  geom_col(fill = "darkgreen")

Cycle 3: Small Multiples & Trendlines

Faceting: The Power of Small Multiples

Instead of cramming 6 groups into one messy plot, split your plot into small multiples!

1. facet_wrap(~ variable)

Splits by a single categorical variable across rows and columns:

ggplot(airquality, aes(x = Temp, y = Ozone)) +
  geom_point(color = "navy", alpha = 0.7) +
  geom_smooth(method = "lm", se = FALSE, color = "red") +
  facet_wrap(~ Month, nrow = 1)

2. facet_grid(var1 ~ var2)

Forms a 2D matrix of subplots (rows $ imes$ cols):

# Example syntax:
# facet_grid(sex ~ smoker)

Controlling Facet Scales

By default, all facets share the exact same \(x\) and \(y\) axis limits (scales = "fixed").

# Allow each facet to have its own independent y-axis limit:
facet_wrap(~ Month, scales = "free_y")

# Allow both axes to vary freely:
facet_wrap(~ Month, scales = "free")

Note

Keep scales fixed when comparing absolute magnitudes across groups; use free_y when inspecting internal shapes of skewed sub-populations.

Cycle 4: Polishing Publication-Ready Graphics

Labels, Titles, and Captions: labs()

A plot is only as good as its labels. Never leave raw code names (Temp, Solar.R, Month) on a final figure!

p_final <- ggplot(airquality, aes(x = Temp, y = Ozone, color = Wind)) +
  geom_point(size = 3, alpha = 0.8) +
  geom_smooth(method = "lm", color = "black", linetype = "dashed", se = FALSE) +
  labs(
    title = "Air Quality & Ozone Concentrations in New York City",
    subtitle = "Daily measurements from May to September 1973 (LaGuardia Airport)",
    x = "Maximum Daily Temperature (°F)",
    y = "Mean Ozone (parts per billion)",
    color = "Wind Speed\n(mph)",
    caption = "Source: New York State Department of Environmental Conservation"
  )

Color Palettes & Built-In Themes

Accessible Palettes

# Continuous Viridis
p_final + scale_color_viridis_c(option = "magma")

# Discrete Brewer
# scale_fill_brewer(palette = "Dark2")

Clean Themes

# theme_minimal() or theme_classic()
p_final + 
  scale_color_viridis_c(option = "viridis") +
  theme_minimal(base_size = 13) +
  theme(
    legend.position = "right",
    plot.title = element_text(face = "bold", size = 15)
  )

Saving High-Resolution Figures: ggsave()

# Saves the last displayed plot (or a specified plot object)
ggsave(
  filename = "figures/fig1_ozone_temperature.png",
  plot = p_final,
  width = 8,
  height = 5,
  dpi = 300  # Publication quality
)

AI Corner: The Truncated Axis & Overplotting Trap

Spotting Misleading Visuals

❌ What AI Generated

# AI Prompt: "Plot hospital admissions by month"
# AI code:
ggplot(df, aes(x = month, y = rate)) +
  geom_col() +
  coord_cartesian(ylim = c(45, 52)) # Truncated!

The Danger: Truncating the \(y\)-axis baseline on bar charts creates optical illusions, making a 2% fluctuation look like a 500% surge!

✅ The Verified Standard

  • Bar charts MUST start at 0: Always include the zero baseline for area/length geoms (geom_col, geom_bar).
  • For Overplotting: Use geom_jitter(), alpha < 0.5, or 2D density contours rather than overlapping solid points.
  • Color Accessibility: Always test palettes with colorblind simulators (viridis is colorblind-friendly by default).
