if: Run Code Conditionally

sbp <- 165

if (sbp >= 180) {
  print("Hypertensive crisis: seek care immediately")
} else if (sbp >= 140) {
  print("Stage 2 hypertension")
} else if (sbp >= 130) {
  print("Stage 1 hypertension")
} else {
  print("Not hypertensive")
}
  • The condition must be a single TRUE or FALSE.
  • Branches are checked top to bottom; the first match wins: order matters!

if Traps to Avoid

Vector condition = error

sbp_vec <- c(120, 165, 190)
if (sbp_vec >= 140) { ... }
# Error: the condition has length > 1

if inspects one value; vectors need ifelse() (next!).

NA condition = error

x <- NA
if (x > 5) { ... }
# Error: missing value where
# TRUE/FALSE needed

Guard first: if (!is.na(x) && x > 5).

Vectorized Decisions: ifelse()

ifelse(condition_vector, value_if_true, value_if_false) decides element by element:

sbp_vec <- c(120, 165, 190, 135)

ifelse(sbp_vec >= 140, "elevated", "normal")
#> "normal" "elevated" "elevated" "normal"
# Perfect inside mutate()
gm |>
  filter(year == 2008) |>
  mutate(le_group = ifelse(life_expectancy >= 75, "high", "lower"))

Many Categories: case_when()

Nested ifelse() calls get unreadable fast: dplyr::case_when() scales cleanly:

gm |>
  filter(year == 2008) |>
  mutate(bp_stage = case_when(
    child_mortality >= 100 ~ "very high",
    child_mortality >= 50  ~ "high",
    child_mortality >= 10  ~ "moderate",
    !is.na(child_mortality) ~ "low",
    TRUE ~ NA
  ))
  • Conditions are checked in order; first TRUE wins (like else if chains).
  • The final TRUE ~ ... is the catch-all “else”.

Cycle 2: for Loops

The for Loop

Repeat a code block once per element of a vector:

sites <- c("Brooklyn", "Queens", "Bronx")

for (s in sites) {
  print(paste("Auditing site:", s))
}
# Looping over positions with seq_along()
wait_times <- c(45, 12, 85, 30)

for (i in seq_along(wait_times)) {
  print(paste("Patient", i, "waited", wait_times[i], "minutes"))
}
  • Use seq_along(x), never 1:length(x): it behaves correctly when x is empty.

The Accumulator Pattern

Build a result before the loop, fill it inside the loop:

# Cumulative case counts over an outbreak week
daily_cases <- c(3, 7, 12, 20, 31, 26, 18)

total_so_far <- numeric(length(daily_cases))  # pre-allocate!
running_total <- 0

for (i in seq_along(daily_cases)) {
  running_total <- running_total + daily_cases[i]
  total_so_far[i] <- running_total
}

total_so_far
#> 3 10 22 42 73 99 117

Tip

Pre-allocating with numeric(n) beats growing a vector with c() inside the loop: both cleaner and dramatically faster.

Vectorize First, Loop Second

Most “loops” in R are already built in:

Loop version Vectorized version
sum with accumulator sum(x)
running total loop cumsum(x)
elementwise transform loop x * 2, log(x)
conditional relabel loop ifelse(...)

Reach for a loop when steps depend on previous results (simulations, iterative algorithms) or when you must produce side effects (saving files, printing reports).

Cycle 3: while Loops

while: Repeat Until a Condition Fails

Use when you don’t know in advance how many iterations you need:

# An intervention cuts weekly cases by 20%.
# How many weeks until fewer than 10 cases?
cases <- 200
weeks <- 0

while (cases >= 10) {
  cases <- cases * 0.8
  weeks <- weeks + 1
}

weeks    # 14
cases    # 8.8

while Safety Rules

1. The condition must eventually fail

while (cases >= 10) {
  # forgot to update cases...
  weeks <- weeks + 1
}
# infinite loop! (Esc to stop)

2. Add a guard rail

while (cases >= 10 && weeks < 1000) {
  cases <- cases * 0.8
  weeks <- weeks + 1
}

A hard cap turns a hang into a debuggable result.

Warning

Every while body must move the state toward the exit condition.

Combining Loops with Last Week’s Tools

Loop over groups, applying a full pipeline each time:

continents <- c("Africa", "Asia", "Europe")

for (ct in continents) {
  n_hi <- gm |>
    filter(year == 2008, continent == ct,
           !is.na(life_expectancy), life_expectancy >= 75) |>
    nrow()
  print(paste(ct, "has", n_hi, "countries with life expectancy >= 75"))
}

AI Corner: The Unnecessary Loop

Asked to flag high-mortality countries, an AI wrote:

flags <- c()
for (i in 1:nrow(df)) {
  if (is.na(df$child_mortality[i])) {
    flags <- c(flags, NA)
  } else if (df$child_mortality[i] > 50) {
    flags <- c(flags, "high")
  } else {
    flags <- c(flags, "low")
  }
}

Audit findings:

  1. Growing flags with c() re-copies the vector every iteration: quadratic slowdown.
  2. 1:nrow(df) breaks on an empty data frame (1:0 runs twice!).
  3. Three branches of loop for what one vectorized line does:
flags <- ifelse(df$child_mortality > 50, "high", "low")   # NA stays NA for free

Important

Correct output is not enough: audit AI code for idiom and scalability too.
